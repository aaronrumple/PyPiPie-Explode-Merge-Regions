Merge Regions

PyPiPie / pyRevit Help — Filled Regions and Masking Regions

Purpose

Merge Regions combines two or more selected Filled Regions and/or Masking Regions into a single resulting region. Overlapping filled areas are unioned while holes and nested filled islands are retained so the result matches the visible geometry of the selected regions.

The command works in the active view and accepts preselected regions. If fewer than two valid regions are preselected, it prompts you to select regions.

Basic Workflow

  1. Select two or more Filled Regions and/or Masking Regions in the active view.
  2. Run Merge Regions.
  3. Choose the resulting region kind and type.
  4. Choose whether to keep the original regions.
  5. Choose whether to preserve boundary line styles or replace them with one selected line style.
  6. Click Merge.

The newly created region is selected when the command completes. The pyRevit output reports the input count, merged components, resulting boundary loops, result type, original-region disposition, line-style action, and a clickable output ElementId.

Dialog Options

OptionBehavior
ResultChoose Filled Region or Masking Region.
Filled Region TypeSelects the Revit Filled Region Type used by the result. When all selected regions are Filled Regions of the same type, Keep Current Filled Region Type is available as the default.
Keep originalsChecked: source regions remain. Unchecked: source regions are deleted after a successful merge.
Keep boundary line stylesAttempts to preserve the styles of surviving source edges. New edges produced by overlap/union geometry may not have an unambiguous source edge.
Replace all boundary line stylesEnables the line-style dropdown and applies the selected style to all boundaries of the resulting region.

Graphic Examples

1. Overlapping regions

Result: the overlapping filled areas become one continuous region. The internal overlap edges disappear.

2. Hole

A boundary contained inside a filled outer boundary is maintained as a hole.

3. Island inside a hole

The filled area nested inside a hole is an island. It remains filled rather than being discarded as another hole.

4. Multiple nesting levels

Nesting follows alternating visual parity: fill → hole → island → hole. Additional nesting levels follow the same pattern.

Geometry Rules

  • Regions that genuinely overlap are unioned.
  • Disjoint filled areas can remain separate filled components within the resulting region.
  • Contained loops are evaluated as holes or islands according to their nesting.
  • The command operates on regions owned by the active view.
  • The merge must produce valid, planar Revit region boundaries. Invalid/intersecting output loops cause the operation to fail and the transaction is rolled back.
Important: “Keep boundary line styles” is best-effort. A boundary segment created by the union of two regions did not necessarily exist as a source segment, so it may not have a unique original line style to preserve. Use Replace all boundary line styles when every resulting boundary must use one known style.

Examples of What to Select

Same type: Select several overlapping Filled Regions that all use the same type. The dialog offers Keep Current Filled Region Type.

Different filled types: Select Filled Regions using different types. Choose the desired resulting Filled Region Type from the dropdown.

Mixed filled + masking: Select both kinds, then explicitly choose whether the result is a Filled Region or Masking Region.

Ring with an island: Select the region geometry containing the outer fill, inner hole, and nested island together with any other regions to merge. The nested island should remain visibly filled in the result.

Failure / Troubleshooting

  • Nothing happens: confirm at least two valid regions are selected in the active view.
  • Merge fails: check for malformed, self-intersecting, extremely short, or otherwise invalid region boundaries.
  • Unexpected missing island/hole: review the pyRevit report, especially Merged filled components and Result boundary loops.
  • Unexpected boundary style: rerun with Replace all boundary line styles and select the desired line style.

The command performs the creation/deletion in a Revit transaction. If creation fails, the transaction is rolled back so the selected source regions are not intentionally deleted by the failed operation.
