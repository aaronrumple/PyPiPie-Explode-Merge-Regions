Explode Regions

PyPiPie — Filled Regions / Masking Regions

Purpose

Explode Regions separates a Filled Region or Masking Region containing multiple disconnected solid areas into individual Revit region elements while preserving holes and nested islands.

The command determines the nesting relationship of every closed loop. It does not depend on the order in which Revit returns region boundaries.

Type preservation: Filled Regions retain the original FilledRegionType. Masking Regions remain Masking Regions. The tool also attempts to restore the original boundary line styles.

How to Use

  1. Select one or more Filled Regions and/or Masking Regions. Regions may be preselected before starting the command.
  2. Run Explode Regions.
  3. Choose Keep original regions or Delete original regions.
  4. Click OK.
  5. Each independent solid island is created as its own Revit region. Holes belonging to that island remain holes.

How Nesting Is Interpreted

Nesting depthMeaningExplode result
0Outer solidNew region
1HoleHole in depth 0 region
2IslandNew region
3Hole in islandHole in depth 2 region
4Nested islandNew region
Rule: Every even nesting depth is solid material and becomes a region. Its immediate odd-depth children are retained as holes.

Boundary Line Styles

The command attempts to preserve the original boundary line styles, including regions whose loops use different styles. Style data is read from the source region's dependent Revit sketch curves and matched to the corresponding new boundaries.

Revit may split, merge, reverse, or re-parameterize curves while creating a region, so matching is performed within the island and its holes rather than relying only on identical curve endpoints.

View Orientation

Loop containment is evaluated in the owning view's local Right/Up plane. This supports plan views as well as vertical views such as sections and elevations.

Keep or Delete Originals

OptionBehavior
Keep original regionsCreates the exploded regions and leaves the selected source regions unchanged. Recommended when checking complex geometry.
Delete original regionsCreates the exploded regions and removes each successfully processed source region.

Important Notes

  • Works with Filled Regions and Masking Regions.
  • Filled Regions retain the exact source Filled Region type.
  • Masking Regions remain Masking Regions.
  • Multiple selected source regions are processed independently.
  • Disconnected solid areas become separate region elements.
  • Interior holes remain with the appropriate enclosing region.
  • Nested islands become independent regions.
  • Boundary line styles are restored where they can be matched reliably.
  • Touching or coincident boundaries can be geometrically ambiguous and should be reviewed.

Recommended Workflow

For complex geometry, first use Keep original regions. Compare the exploded result with the source, especially nested islands, holes, and non-default boundary line styles. Once verified, delete the original manually or rerun using Delete original regions.
