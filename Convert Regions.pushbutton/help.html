Convert Region

Convert Revit Filled Regions to Masking Regions and Masking Regions to Filled Regions while preserving boundary geometry and mixed line styles.

What This Tool Does

The tool converts selected detail regions in either direction:

Selected elementResultAdditional input
Filled RegionMasking RegionNone
Masking RegionFilled RegionSelect the Filled Region type to use
Mixed selectionEach element converts to the opposite kindFilled Region type is requested once for all Masking → Filled conversions
Mixed selections are supported. A Filled Region and a Masking Region can be selected together; each converts independently to the opposite kind.

How to Use

  1. Preselect one or more Filled Regions and/or Masking Regions, or run the tool and select them when prompted.
  2. If the selection contains any Masking Regions, choose the Filled Region type to use for the Masking → Filled conversion.
  3. The tool creates replacement regions, restores each boundary segment's line style, verifies the result, and then removes the originals.
  4. The newly created regions remain selected, making it easy to run the tool again to reverse the conversion.

Mixed Boundary Line Styles

Boundary segments can use different Revit line styles. The tool preserves those styles segment-by-segment instead of applying a single line style to the entire replacement region.

Each replacement boundary curve is matched back to the corresponding source boundary and receives its original line style.
Because Revit caches region graphics, the tool commits the line-style edits and then performs a separate refresh step before verification.

Selection and Type Behavior

Preselection

If valid regions are already selected, the tool uses them immediately.

No Preselection

If no valid regions are selected, Revit prompts you to pick Filled or Masking Regions.

Filled Region Type dialog: this dialog appears only when at least one selected source is an actual Masking Region. The chosen Filled Region type is applied only to Masking → Filled conversions.

Safety and Verification

The conversion is performed as a transaction group. Before the original regions are deleted, the tool verifies the replacement geometry and boundary styles.

  • If the boundary segment count changes, the conversion is rejected.
  • If a source boundary cannot be matched to a replacement boundary, the conversion is rejected.
  • If an original line style cannot be restored, the conversion is rejected.
  • If the operation fails, the transaction group rolls back rather than leaving a partially converted set.

Output

The pyRevit output window reports the selected counts, conversion counts, failures, direction of each conversion, original ElementId, and the new clickable ElementId.

Notes

  • The tool operates on Revit FilledRegion elements, including actual Masking Region instances.
  • The element kind is determined from FilledRegion.IsMasking.
  • A Filled Region type's own masking/opaque display setting is not used to decide whether the element is a Masking Region.
  • Pinned state is retained when Revit permits it.
