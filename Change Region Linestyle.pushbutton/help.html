Change Region Linestyle

PyPiPie — Filled Region and Masking Region boundary utility

Changes all boundary lines of selected Filled Regions and Masking Regions to a user-selected Revit line style.

What This Tool Does

The tool changes the boundary line style of one or more selected regions. Both Filled Regions and Masking Regions are supported and use the same operation.

Regions are modified in place. The tool does not delete or recreate the region, so the existing region element remains in the model.

How to Use

  1. Select one or more Filled Regions and/or Masking Regions in Revit.
  2. Run Change Region Linestyle.
  3. Select the desired line style from the list.
  4. Click Change Linestyle.
  5. Review the pyRevit output report for changed or failed regions.

If no valid region is preselected, the tool prompts you to select regions in the active view.

Filled and Masking Regions

Region Supported Behavior
Filled Region Yes All region boundary lines are changed to the selected line style.
Masking Region Yes All region boundary lines are changed using the same Revit region API.
Mixed selection Yes Filled and Masking Regions can be processed together.

Line Style Selection

The list contains line styles that Revit identifies as valid for region boundaries. When multiple regions are selected, the tool uses line styles valid for the entire selection.

The selected style is applied to the entire boundary. Existing mixed boundary styles are replaced by the selected style.

Selection Behavior

  • If regions are already selected, the tool uses the preselection immediately.
  • Non-region elements in the preselection are ignored.
  • If no regions are preselected, Revit prompts for Filled or Masking Regions.
  • Multiple regions can be processed in one operation.
  • Canceling the selection or line-style dialog makes no model changes.

What Is Preserved

Because the region itself is changed rather than rebuilt, the tool does not intentionally alter the region's geometry or other instance information.

  • Region ElementId
  • Boundary geometry
  • Holes and islands
  • Filled Region type and fill pattern
  • Instance parameters
  • Extensible Storage attached to the existing element
  • Location and view association

Error Handling

Each region is processed independently inside the overall Revit transaction. If one region cannot be changed, that region is rolled back without intentionally undoing successful changes to other selected regions.

The final pyRevit report includes:

  • Total selected regions
  • Number successfully changed
  • Number that failed
  • Clickable ElementIds for changed regions
  • Error reason for any failed region

Revit API Method

The tool uses Revit's purpose-built FilledRegion boundary line-style methods rather than manipulating the region's underlying sketch curves:

GetValidLineStyleIdsForFilledRegion(doc)

SetLineStyleId(selected_style.Id)

These methods work for both Filled Regions and Masking Regions.

Notes

  • The command changes every boundary segment of each selected region to one line style.
  • It is not intended for changing only individual edges of a region.
  • The available line-style list is controlled by the styles Revit permits for region boundaries.
  • The region is not exploded, recreated, or converted.
